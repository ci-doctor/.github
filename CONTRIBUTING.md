# Contributing to ci-doctor

Thanks for helping. Each repository has its own guide:

- **The analyzer, the CLI and the docs:** [ci-doctor/CONTRIBUTING.md](https://github.com/ci-doctor/ci-doctor/blob/master/CONTRIBUTING.md)
- **Matchers:** [matchers/CONTRIBUTING.md](https://github.com/ci-doctor/matchers/blob/main/CONTRIBUTING.md)

Not sure where something belongs? Open an issue on [ci-doctor](https://github.com/ci-doctor/ci-doctor/issues/new/choose),
or write to [support@cidoc.dev](mailto:support@cidoc.dev).
